# CSFD Extensions

Browser extension pro rozšíření funkcionality [CSFD.cz](https://www.csfd.cz) - České a Slovenské filmové databáze.

## 🎬 Funkce

### Vyhledávání
- **Rychlé vyhledávání** filmů přímo z panelu nástrojů prohlížeče
- Snadný přístup k CSFD databázi bez nutnosti otevírat web

### Rozšíření CSFD stránek
- **IMDB hodnocení** - zobrazení hodnocení z IMDB přímo na CSFD stránkách
- **Originální jazyk** - zobrazení jazyka originálu filmu
- **Tooltip pro filmy** - informační bublina po najetí myší nad odkaz filmu
- **Tooltip pro tvůrce** - informační bublina po najetí myší nad odkaz tvůrce
- **Odkaz na top stránky** - rychlý přechod na začátek stránky

### Chrome Web Store
*Připravuje se*

## ⚙️ Nastavení

Po instalaci můžete upravit nastavení rozšíření kliknutím pravým tlačítkem na ikonu rozšíření a výběrem "Možnosti" nebo přes stránku rozšíření v prohlížeči.

### Dostupné možnosti:
- Zapnout/vypnout IMDB hodnocení
- Zapnout/vypnout zobrazení originálního jazyka
- Zapnout/vypnout odkaz na vrch stránky
- Zapnout/vypnout tooltip pro tvůrce
- Zapnout/vypnout tooltip pro filmy
